EPOCH

Static site — no backend required:

    cd ready-to-run
    npx serve

PowerShell: use npx.cmd serve if npx.ps1 is blocked.
Open the Local URL printed by serve (normally http://localhost:3000).
Sparse Canada globe: http://localhost:3000/?mode=ml&view=overview
Or choose MLP research, then Canada overview / 3D.
The globe includes bundled Earth imagery, cached layers, filters and downloads.
See ML-OVERVIEW.md for the meaning and limits of the sampled historical data.

50.6M model presentation (one command from this folder):

    .\run-ml-viewer.cmd

Or double-click run-ml-viewer.cmd. It opens:
    http://127.0.0.1:8000/?mode=ml

Keep its server window open. Ctrl+C stops it. All 1,608 processed scenes,
22,174,168 query scores and 8,040 rendered views are already prepared.
Use Present scenes for the tour, and Image PNG to export a view for slides.
Setup and presenter notes: ML-PRESENTATION.md.
This is cached research, not live monitoring. The original small-model globe
remains at http://127.0.0.1:8000/?mode=ml&view=inspect (MLP-INTEGRATION.md).

Quickest: the built site is in ready-to-run/. It has to be served, not double-clicked
(browsers will not load it from a file:// address). From this folder:

    cd ready-to-run
    python3 -m http.server 8080        (or: npx serve -l 8080)

then open http://localhost:8080/ for the burning activity calendar and
http://localhost:8080/?mode=scenarios for the response scenarios.

From source (needs Node 20 or newer):

    cd frontend
    npm install
    npm run dev

Needs an internet connection for the web font (IBM Plex; it falls back to the system font
offline) and for the optional satellite image
layer; everything else is bundled. Works best in a desktop Chrome, Edge or Firefox window
about 1440 px wide or more. See README.md for what it does and where the data comes from.

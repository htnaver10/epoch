EPOCH | Run the UI

1. Extract the ZIP.
2. Double-click START-UI.cmd (Windows), or run the following command
   from the EPOCH folder:

   python -m http.server 8080 --bind 127.0.0.1 --directory ready-to-run

3. Open http://127.0.0.1:8080/

To inspect pre-VIIRS model results, select 2003–2011 and click PLSWORK
under Show. Use Full summer to see all available processed scene dates.

Calendar:      http://127.0.0.1:8080/?year=2004
MLP research:  http://127.0.0.1:8080/?mode=ml
Scenarios:     http://127.0.0.1:8080/?mode=scenarios

The historical layer contains real inference for 648 archived cell-days
across 10 dates, with results in each year from 2003 through 2011.
Only processed and eligible Aqua MODIS observations have model scores.
No-coverage dates/areas display a message. Inference was stopped at the
user's request. PREDICTION-COVERAGE.json has the exact coverage by year.

The MLP research tab also includes the separate saved June 2024 benchmark
of 84 patches. The main activity calendar and ranks use archived FIRMS
observations. CSV export switches to scored model cells while the
PLSWORK layer is selected. Switch back to MODIS for archived counts.

Python is required to serve the app. Optional map imagery and web fonts
use the internet. The calendar, scenarios and prediction snapshots are
included in the ready-to-run folder. The verified PLSWORK inference
checkpoint is included for future runs.

Development:
  cd frontend
  npm ci
  npm run dev

The source also includes backend/viewer.py and MLP-INTEGRATION.md for
the optional local API server. The static UI works from the command
above. No model training or inference starts when the UI is served.
